## 3. 三个致命误判（全踩过）

### 3.1 误判一：用 R−G 判断黄金

| 错误结论 | 真相 |
|---|---|
| "R−G=64 是木头，R−G=16 才是纯黄" | **错**。棕与金的色相都在 38°~45°（R−G≈50~75）。棕像木头是**明度低 + B 高**，不是 R−G 大 |

### 3.2 误判二：用 #E8D838 当底色

| 错误结论 | 真相 |
|---|---|
| "亮黄就是 #E8D838" | **错**。色相 54.5°（接近 60° 正柠檬），B=56 偏高 → 发酸发绿的**柠檬奶酪色** |

### 3.3 误判三：问号吸色

| 错误结论 | 真相 |
|---|---|
| "问号是 #D89808 琥珀色" | **错**。那是**背光面**颜色（MC 侧面 ×0.6 暗化 + 石砖 AO 混合）。问号本体是**暖白 #FFFDF4** |

## 4. 黄金色的正确数学约束

```
R ∈ [245, 255]     ← 必须极高
G ∈ [160, 208]     ← 暖金区间（R−G ∈ [50, 85]）
B ∈ [  4,  28]     ← 死死压低（这是命门）
```

| 颜色 | RGB | B | 观感 |
|---|---|---|---|
| 木头（v5） | (168,122,38) | 38 | 明度 50%，发闷 |
| 柠檬奶酪（v6） | (232,216,56) | **56** | 发酸、发绿 |
| **真黄金（定稿）** | (248,184,18) | **18** | 浓郁赤金/琥珀金 |

```javascript
const PALETTE = {

  'H': [255, 234,  92], // #FFEA5C 四角内铆钉高光（亮金白）
  'R': [212, 110,   6], // #D46E06 内角过渡 & 问号防漏边描线
  'O': [226, 134,   8], // #E28608 外圈深橘金
  'D': [238, 158,  12], // #EE9E0C 中外圈浓郁金
  'G': [248, 184,  18], // #F8B812 中圈正黄金
  'M': [255, 208,  28], // #FFD01C 中心区域高光亮金
  'S': [164,  70,   4], // #A44604 问号左侧/下方深浮雕阴影槽
  'W': [255, 253, 244], // #FFFDF4 问号本体（高光暖白）
  'w': [255, 240, 200], // #FFF0C8 问号本体右下边缘（暖奶油白）
};
```

**三层空间纵深结构（"宝箱感"的来源）：**

| 层 | 组成 | 作用 |
|---|---|---|
| 第一层 外围束缚 | 四边全闭合深琥珀外框 + 1 格内圈暖橙过渡 + 四角亮金铆钉 H | 把视觉重心锁在方块内部 |
| 第二层 球面光泽 | 底色以 (7.5,7.5) 为圆心径向阶梯：M(中心亮金)→G(正金)→D(橘金)→O(外圈) | 模拟黄金表面微微隆起 |
| 第三层 内嵌浮雕 | 问号用 S 打左侧/下方重阴影 + R 做右侧/上方 1 格包边 | 让白问号像嵌进黄金凹槽的象牙 |

### 6.1 问号几何规格（坐标 0~15）

| 部位 | 规格 |
|---|---|
| 顶部横梁 | y=2，宽 6 格（x=5..10） |
| 顶弧外扩 | y=3..4，向左右各扩 1 格，总宽 8 格（x=4..11） |
| 左侧内钩 | 宽 2 格（x=4..5），向下延伸到 y=5，y=6 留深色底阴影 |
| 右侧弯弧 | 宽 2~3 格（x=9..11），y=6..7 向中间收拢 |
| 中心竖杆 | 居中宽 2 格（x=7..8，y=7..9） |
| 间隔 | y=10 是 1 格高的深色阴影间隙 |
| 底部圆点 | **严格 2×2 正方形**（x=7..8, y=11..12），y=13 是底部阴影 |

**关键：竖杆和圆点必须严格对齐在 x=7,8 两列**，否则不对称。

## 7. 逐面明度系数

| 面 | 乘数 [R,G,B] | 主体金 #F8B812 结果 | 说明 |
|---|---|---|---|
| 顶面 Top/+Y | `[1.00, 1.00, 1.00]` | `#F8B812` | **严格保持贴图原色** |
| 右前受光 Right | `[0.84, 0.80, 0.72]` | `#D0930D` | 暖向压暗，绝不偏绿 |
| 左前背光 Left | `[0.68, 0.62, 0.52]` | `#A97209` | 深邃琥珀金阴影 |

**实现方式**：把系数**烘焙进贴图**（生成三张独立 PNG）。

```
up / down     → top   贴图
north / south → left  贴图
east / west   → right 贴图
```
